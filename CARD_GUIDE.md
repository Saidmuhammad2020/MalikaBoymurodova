# Цифровая визитка — Боймурадова Малика Собировна

Адаптивный одностраничный сайт-визитка (One Page) для исполнительного директора
**ООО «Финтехстан Таджикистан»** со встроенным QR-кодом для мгновенного перехода.

Без сборки и зависимостей — чистые HTML/CSS/JS. Открывается даже двойным
кликом по `index.html`.

---

## 📁 Структура

```
index.html                     ← разметка и SEO-теги
.nojekyll                      ← корректная отдача файлов на GitHub Pages
assets/
  css/styles.css               ← оформление и брендовые цвета (раздел :root)
  js/app.js                    ← данные (CONFIG), QR-код, vCard, копирование
  img/logo.svg                 ← знак FintechStan (можно заменить оригиналом)
  img/avatar-placeholder.svg   ← заглушка фото (монограмма «МБ»)
  img/favicon.svg              ← иконка вкладки
  img/og-cover.svg             ← превью для соцсетей
  img/malika.jpg               ← ⚠️ сюда положите настоящее фото (см. ниже)
```

---

## 🖼 Как добавить фото

Положите портрет по пути **`assets/img/malika.jpg`**.
До этого автоматически показывается элегантная заглушка с монограммой.

Рекомендации к фото:
- квадрат (1:1), например **800 × 800 px**;
- формат `.jpg` (или замените имя файла в `index.html`, если `.png`/`.webp`);
- лицо по центру — изображение обрезается в круг.

## ✏️ Как изменить содержимое

| Что меняем | Где |
|---|---|
| Имя, должность, компания, текст «о себе», теги | `index.html` (видимый текст) |
| Телефон, e-mail, сайт, ссылки `tel:`/`mailto:` | `index.html` **и** объект `CONFIG` в `assets/js/app.js` |
| Адрес визитки для QR/vCard (резервный) | `CONFIG.url` в `assets/js/app.js` |
| Цвета, шрифты, скругления, тени | раздел `:root` в `assets/css/styles.css` |
| Структурированные данные (schema.org) | блок `application/ld+json` в `index.html` |

> Контактные данные продублированы в `CONFIG` намеренно — оттуда строятся
> QR-код и файл контакта (vCard). Меняйте в обоих местах.

## 🔳 QR-код

- На странице QR **всегда указывает на текущий адрес сайта** — где бы он ни был
  размещён (определяется автоматически из адресной строки).
- Кнопки под QR:
  - **PNG** — растровый файл ~1200 px (для печати и соцсетей);
  - **SVG для печати** — вектор без потери качества (для типографии).
- При локальном открытии (`file://`) QR использует резервный адрес из `CONFIG.url`.

## 🚀 Публикация (выбран отдельный репозиторий → чистый адрес)

Итоговый адрес: **https://saidmuhammad2020.github.io/**

1. Создайте новый публичный репозиторий с именем **`saidmuhammad2020.github.io`**.
2. Скопируйте в его корень всё содержимое: `index.html`, папку `assets/`, `.nojekyll`.
3. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch**,
   ветка `main`, папка `/ (root)` → **Save**.
4. Через 1–2 минуты сайт доступен по адресу **https://saidmuhammad2020.github.io/**.

Файлы в этом репозитории уже лежат в корне — их достаточно просто перенести.

### Свой домен (необязательно)
Если позже понадобится, например, `card.fintechstan.uz`:
добавьте файл `CNAME` с доменом, пропишите DNS-запись `CNAME → saidmuhammad2020.github.io`,
включите домен в Settings → Pages и обновите абсолютные адреса
(`canonical`, `og:*`, `CONFIG.url`).

## 🎨 Брендинг

Все цвета вынесены в переменные в начале `assets/css/styles.css` (`:root`):
глубокий синий `--navy`, лазурь `--azure`, светло-голубой `--sky`,
графит `--slate` — палитра логотипа FintechStan. Поменяв 3–4 значения,
можно перекрасить всю визитку.

Чтобы поставить оригинальный логотип — замените `assets/img/logo.svg`.

## 🔌 Внешние ресурсы

Страница подключает два проверенных CDN (кэшируются глобально, грузятся быстро):

- **Шрифты** Inter и Manrope — Google Fonts.
- **Генератор QR** `qrcode-generator@1.4.4` — jsDelivr, закреплён по SRI-хэшу
  (`integrity="sha384-…"`), поэтому подмена файла невозможна. Если скрипт по
  какой-то причине не загрузится, под QR появится обычная кликабельная ссылка.

Чтобы сделать визитку полностью автономной (без CDN), можно скачать
`qrcode.js` и положить его в `assets/js/vendor/`, заменив тег `<script>`
в `index.html` на локальный путь.
